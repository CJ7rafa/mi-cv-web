Despacho

Sistema Integral de Gestión Académica (Java) Desarrollo de una aplicación de escritorio robusta orientada al dominio de Estructuras de Datos Avanzadas y Programación Orientada a Objetos. El sistema permite la administración de entidades (Clientes, Empleados, Productos) mediante la implementación manual de listas simples, dobles, pilas y colas, evitando el uso de librerías externas para profundizar en la lógica de punteros y gestión de memoria. Incluye módulos de búsqueda optimizada, algoritmos de ordenamiento recursivos y una interfaz gráfica desarrollada en Swing (JFrames) con un sistema estricto de validación de datos para garantizar la integridad de la información.

Java SE Apache NetBeans Algoritmo Swing/GUI Recursividad
